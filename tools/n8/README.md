# tools/n8 — compliance, robustness, secrets & hygiene tooling (Track B)

All tools print counts, ids (sha8/job8) and field names only — never statement
content, filenames (beyond sha8-derived synthetic names), or secret values.
`.local/` holds probes and raw outputs and is gitignored.

## Files

| tool | purpose | usage |
|---|---|---|
| `retention_probe.py` | inventory every sink for one job_id (S3, audit tables, redis, temp) before/after `sweep_once()` | copy into `onb_backend` (`docker exec -i sh -c 'cat > /tmp/rp.py'`), run with `PYTHONPATH=/app`: `python /tmp/rp.py <job_id> before|after` |
| `secret_scan.py` | rule-based secrets scan over working tree and `git log -p --all`; reports path/commit/rule only | `python tools/n8/secret_scan.py --tree` / `--history` |
| `big_run.py` | async-process the largest corpus PDFs; records status, wall-time, `docker stats` mem peak | `python tools/n8/big_run.py` (paths hard-coded to corpus) |
| `.local/probes/*` | synthetic HDFC-shaped PDFs (reportlab) | generated by `tools/verify/gen_probe_pdf.py` |
| `.local/malformed/*` | zero-byte, wrong-ext, 1000-page, wrong-password, corrupt-xref inputs | generated inline (see N8_ROBUSTNESS §d) |
| `.local/big_run.jsonl` | large-file timing results | appended per run |
| `.local/scan_tree.json` `.local/scan_history.json` | scanner output | raw JSON findings (rule+path+commit only) |
| `.local/malformed_results.jsonl` | malformed-input outcomes | per-test http/status/error |

## Measured procedures (repro)

- **Retention**: upload synthetic → `UPDATE user_file_records SET
  retention_expires_at='2020-01-01'` → `RetentionService().sweep_once()` inside
  `onb_backend` → run `retention_probe.py` before/after.
- **Purge rehearsal**: `git clone --no-local <repo> copy` →
  `git filter-repo --replace-text replace.txt --force` → rescan (see
  `docs/security/N8_SECURITY_REVIEW.md`).
- **Mid-flight kill**: submit large job → `docker restart -t 1 onb_backend`
  while status=`running` → poll redis blob + `user_file_records` for honesty.
